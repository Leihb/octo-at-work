# 让 agent 替你干活 · 不写代码，用 octo 把活干完

**你不写代码。你写的是给 agent 看的说明书。**

这是一本给不写代码的打工人的书。工具是 [octo](https://github.com/open-octo/octo-agent)，一个装在你自己电脑上的 agent：
双击安装，选一个模型，然后把活交给它。整理文件夹、一句话出 Excel、会议录音变纪要、把自己账号的评论私信分好类、
每天早上自动跑、在微信里派活。每一章一个真实的活，功能在活里需要的时候才出现，功能速查全在附录。

每一章都有真机跑出来的截图、翻车点，以及花了多少钱、多长时间。

它跟另外两本的关系：《笨办法学 Agent》上册讲一个 agent 里面是什么，下册讲怎么做一个给别人用的 agent 放到线上。
这一本讲自己用。三本可以各自单独读。
